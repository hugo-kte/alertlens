## Triage
- [C2-T1] Identify the internal host involved and the remote endpoint it talks to.
- [C2-T2] Check for periodic connections (beaconing) and unusual processes on the host.
- [C2-T3] Search other hosts for connections to the same remote endpoint.
## Containment
- [C2-C1] Isolate the affected host from the network while preserving its state.
- [C2-C2] Block the remote endpoint at the proxy and firewall.
## Recovery
- [C2-R1] Reimage the host from a known-good source and reset the credentials used on it.
## Evidence
- [C2-E1] Collect a memory image and disk triage package before reimaging.
